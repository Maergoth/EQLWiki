# Contributing to EQLWiki

Fork this repository and create a feature branch from `staging`. Open pull
requests against `staging`. Describe the change and how you checked it.
@Maergoth reviews contributions and controls promotion to `main`.

Accepted changes deploy to the password-protected test wiki at
https://test.eqlwiki.com. Test access is granted separately by the owner.
The production wiki deploys from `main`.

Never commit database dumps, uploaded files, account data, configuration secrets,
or deployment keys. Database and host access are not needed to submit code changes.
See `PROJECT.md` for the application layout and development setup. The repository
contains components with their own licenses; retain their license notices.
